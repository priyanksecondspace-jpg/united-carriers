# United Carriers — recovered front end

Recovered from the public United Carriers website on 12 October 2026 at the owner’s request.

## Run locally

Run `python3 serve.py` from this folder, then open http://localhost:4173.

`dist/` contains the recovered HTML pages, styles, fonts, images, animation frames and JavaScript modules. It can be deployed to a static host. Keep extensionless page routes working, including their directory index files.

The original Webflow project, authoring source, CMS database, account access, order history, backend configuration and service credentials are not included. The JavaScript is the published production bundle, not the original unbundled project. Design and motion were preserved from the published files rather than recreated approximately.

## Production integrations

Contact/career submissions and purchases need your original services reconnected before production use. The restored copy prevents form submissions rather than reporting a false success. External tracking, social, map and carbon calculator links still lead to their original providers. Cookie consent and third-party widgets may depend on their domain settings.

The original domain allowlist in the animation bundle was adapted to accept the restored host. Original branding and agency credits are preserved.

See RECOVERY.json for captured pages/assets and recovery results, and VERIFICATION.md for checks and limits.
